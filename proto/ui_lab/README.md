# UI Lab — ต้นแบบเอฟเฟกต์แสดงผล + ธีมสี (ยังไม่แตะ production)

เปิด `ui_lab_standalone.html` (ไฟล์เดียว ดับเบิลคลิกได้) หรือ `index.html` (ต้องมี `ui.css`, `data.js`, `ui.js` ข้างกัน)

- `build_data.py` → สร้าง `data.js` จาก snapshot ใน `03_website/assets/data/*.json` (อ่านอย่างเดียว) รันซ้ำเพื่อรีเฟรชข้อมูล
- ไม่มี dependency ภายนอก (ยกเว้นฟอนต์ IBM Plex Sans Thai จาก Google Fonts, ไม่มีก็ใช้ฟอนต์สำรอง)

## เอฟเฟกต์ที่ทำแล้ว
1. ฉากอ่างเก็บน้ำ SVG: คลื่น 2 ชั้น, ระดับน้ำพุ่งขึ้นตอนโหลด, เส้นสันสปิลเวย์/เฝ้าระวัง/สูงสุด, ไม้วัดระดับ + ป้ายค่า, น้ำล้น+ฟอง, ฝนตก, ดาว/พระจันทร์ตอนกลางคืน, เรือลอย
2. ตัวเลขนับขึ้น (easeOutQuart), แถบสัดส่วนทิศทางน้ำ, วงแหวนความจุ (ส่วนเกิน 100% เป็นสีแดง), จุด sonar เมื่อมีน้ำล้น, คลื่นตกแต่งการ์ด
3. กราฟระดับน้ำย้อนหลัง 5 วัน ใช้เอฟเฟกต์ river-profile (เส้นสันวาดเข้า + เส้นน้ำจุดไข่ปลา + แรเงาส่วนที่สูงกว่าสัน + เส้นกากบาท/tooltip)
4. กราฟแท่งรายวัน: ตัวเลขส่วนต่างสีแดง/เขียว/ฟ้า, "น้องหยด" เด้งเตี้ย ๆ บนแท่งล่าสุด, ปุ่มสลับข้อมูลมีตัวเลื่อนสไลด์
5. เส้นโค้งพยากรณ์ (cosine interpolation) + marker "ตอนนี้"
6. ตารางสถานี + sparkline, reveal ตอนเลื่อน, skeleton, badge LIVE บอกอายุข้อมูล, แถบย้อนเวลา (เลื่อน/เล่น 79 ช่วง 6 ชม.)
7. ธีมสี: 6 ชุด + เลือกสีเอง, สว่าง/มืด/อัตโนมัติ (ตามเวลา), ลดการเคลื่อนไหว — จำค่าใน localStorage; สีทั้งหมดอนุพันธ์จาก `--accent`/`--accent-2` ด้วย `color-mix`

## หมายเหตุ
- ภาพ/โค้ดเขียนใหม่ทั้งหมด เพียงศึกษาแนวคิดจาก flood.pop.in.th
- กราฟ profile: ความสูงสันเป็นมาตราจริง แต่ส่วนต่างระดับน้ำกับสันขยายให้เห็น (ระบุในกราฟ)
- ถ้าจะนำเข้า production: ย้ายเป็น `assets/css/ui-kit.css` + `assets/js/ui-kit.js` แล้วแทนที่ `data.js` ด้วย fetch จาก JSON จริง
