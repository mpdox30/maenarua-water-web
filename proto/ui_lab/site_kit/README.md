# site_kit — ชั้นธีม + ลูกเล่นสำหรับหน้าเว็บแม่นาเรือเดิม (โครงสร้างหน้าไม่เปลี่ยน)

## ดูพรีวิว (ไม่แก้ไฟล์ production)
```
cd /d D:\maenaruea-water-web\proto\ui_lab\site_kit
python preview_server.py
```
เปิด http://localhost:8001/index.html (ทุกหน้า: water-balance, monitoring, water-demand, ...)
คลิกปุ่มจานสีมุมซ้ายล่างเพื่อเปลี่ยนธีม

## ทำอะไร
- `preview_server.py` แปลงสีฮาร์ดโค้ด (เขียวน้ำทะเล/อำพัน/พื้นหลัง/เส้นขอบ) ใน `<style>` และ `style=""` เป็นตัวแปรธีม แล้วแทรก kit ท้ายหน้า ตอนส่งเท่านั้น
- `theme-kit.js/css` : 6 ชุดสี + เลือกสีเอง + ลดการเคลื่อนไหว (จำค่าไว้), reveal ตอนเลื่อน, ตัวเลข KPI นับขึ้น (ทำงานกับค่าที่ JS ใส่ทีหลังด้วย), skeleton ระหว่างรอค่า "—", ping จุดสถานะ, คลื่นท้าย hero

## เพิ่มในรอบ 2
- `chart-kit.js` (แทรกต่อท้าย chart.umd.min.js อัตโนมัติ): สีกราฟ Chart.js ทุกหน้าเปลี่ยนตามธีม, เส้นกราฟวาดเข้าจากซ้ายไปขวาเมื่อเลื่อนมาถึง
- หน้าคาดการณ์ความต้องการใช้น้ำ: เอฟเฟกต์ river-profile (เส้นเพดาน magnitude ทึบ + เส้น final จุดไข่ปลา + แรเงาส่วนต่าง + จุด/ตัวเลขโผล่ตามเส้น + pulse สัปดาห์สูงสุด)

- แก้บั๊กรอบแรก: กฎแปลงสีไปแปลงใน `:root{}` ทำให้ตัวแปรอ้างวนตัวเอง (พื้นหลังขาว/ตัวหนังสือจาง) ตอนนี้ข้าม `:root` แล้ว
